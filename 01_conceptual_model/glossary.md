**Глоссарий (дополненный под модель данных)**

| Термин | Определение |
|---|---|
| **Отель** | Объект размещения, с которым у туроператора заключён договор. |
| **Категория номера** | Тип номера в отеле (стандарт, люкс и т.д.), характеристика номерного фонда. |
| **Номерной фонд** | Совокупность номеров определённой категории в отеле. |
| **Квота** | Выделенное количество номеров, доступных для продажи через туроператора на определённый период. |
| **Тарифный план** | Набор условий продажи (цена, правила отмены, план питания). |
| **Цена** | Стоимость проживания в номере на конкретную дату для конкретного тарифного плана. |
| **Канал продаж** | Внешняя система (OTA, сайт туроператора, агрегатор), куда публикуется доступность. |
| **Публикация** | Факт передачи данных о квоте и ценах в канал продаж. |
| **Stop-sale** | Ограничение продаж на определённые даты или категории номеров. |
| **Овербукинг** | Ситуация, когда количество проданных номеров превышает доступную квоту. |
| **Изменение квоты** | Зафиксированное событие изменения значения квоты (история). |
