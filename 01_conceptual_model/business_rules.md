**Бизнес-правила для модели данных**

| Код | Правило |
|---|---|
| **BR-D1** | Один отель может иметь несколько категорий номеров. |
| **BR-D2** | Одна категория номера относится только к одному отелю. |
| **BR-D3** | Квота задаётся для пары «категория номера — дата» и не может быть отрицательной. |
| **BR-D4** | Квота не может быть уменьшена ниже уже проданного количества. |
| **BR-D5** | Тарифный план привязан к категории номера и действует на определённый период. |
| **BR-D6** | Цена задаётся для пары «тарифный план — дата». |
| **BR-D7** | Канал продаж может быть активным или неактивным. |
| **BR-D8** | Публикация квоты в канал фиксируется с датой и статусом. |
| **BR-D9** | Stop-sale может быть установлен на дату, категорию номера или отель в целом. |
| **BR-D10** | Все изменения квоты и тарифов сохраняются в истории с указанием пользователя и времени. |
