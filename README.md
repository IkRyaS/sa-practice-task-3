# Практика SA. Задание 3: ERD логического уровня для бизнес-функции «Управление квотами и тарифными планами отельера»

**Функция.** Отель-партнёр туроператора самостоятельно задаёт квоты номеров и тарифные планы. Туроператор согласует только значимые изменения. Система публикует актуальную доступность во все каналы продаж и защищает от овербукинга.

Репозиторий продолжает Задание 1 и Задание 2: описание функции и BPMN-схемы дополнены **ERD логического уровня**.

## Содержимое

* `01_conceptual_model/`: глоссарий, бизнес-правила
* `02_logical_model/`: ERD логического уровня (исходник PlantUML, изображения)
* `03_data_dictionary/`: словарь данных (сущности, атрибуты, типы, ограничения)
* `04_validation/`: проверка нормализации (3НФ)

## Модель данных

ERD логического уровня построена для следующих сущностей:
- Отель, Категория номера, Номерной фонд
- Квота, Тарифный план, Цена
- Канал продаж, Публикация
- Изменение квоты (история), Пользователь, Роль
- Ограничение (stop-sale), Овербукинг-инцидент
